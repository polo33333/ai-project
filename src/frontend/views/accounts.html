Chọn cách người dùng bắt đầu chat.

Danh tính được kiểm tra bằng chữ ký token. Người dùng website không được cấp thêm quyền quản trị.

Hướng dẫn kết nối website

Server website cấp token RS256 chứa sub, name, iss, aud, exp, thời hạn tối đa 1 giờ. KnowledgeHub kiểm tra chữ ký bằng khóa công khai, không gọi trực tiếp địa chỉ server.

Đặt đoạn này trước script nhúng. Endpoint website cần kiểm tra phiên đăng nhập và trả {token}; với khách chưa đăng nhập, trả {token:null}.

window.KnowledgeHubIdentity = {
  async getToken(embedId) {
    const response = await fetch('/api/chat-identity?embedId=' + encodeURIComponent(embedId), {
      credentials: 'same-origin', cache: 'no-store'
    });
    if (!response.ok) throw new Error('Không thể xác thực danh tính');
    return (await response.json()).token;
  }
};
